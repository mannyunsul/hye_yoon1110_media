## 1. Railway 백엔드 배포

### 현재 상태
- GitHub 저장소: `https://github.com/mannyunsul/hye_yoon1110_media.git`
- Railway 프로젝트가 이미 연결되어 있다면 `git push`만으로 자동 배포됨

### 신규 배포 시
1. [railway.app](https://railway.app) 접속 → **New Project** → **Deploy from GitHub repo**
2. 저장소 선택 → **Root Directory**: `backend`로 설정
3. **Deploy** 클릭

Railway가 자동으로:
- `nixpacks.toml`을 읽어 Python + yt-dlp + ffmpeg 설치
- `npm install` 후 `node server.js` 시작

### 배포 확인

```bash
# 헬스체크
curl https://YOUR-URL.railway.app/api/health
# 예상 응답: {"status":"ok"}

# 미디어 추출 테스트
curl -X POST https://YOUR-URL.railway.app/api/fetch \
  -H "Content-Type: application/json" \
  -d '{"url": "https://x.com/NASA/status/1234567890"}'
```

### Instagram 이미지 테스트

Instagram 이미지 포스트는 4단계 fallback으로 처리됨:
1. Instagram Private API (쿠키 필요)
2. 임베드 페이지 파싱 (인증 불필요)
3. 직접 페이지 파싱
4. og:image fallback

Railway 로그에서 `[instagram-embed]`, `[instagram-api]`, `[instagram-image]` 로그를 보고 어느 단계가 작동하는지 확인 가능.

## 2. 앱에 Railway URL 적용

**로컬 개발** (`quasar dev`) — `frontend/.env.development`:
```
VITE_BACKEND_URL=http://localhost:3000
```

**APK 빌드** — `frontend/.env.production`:
```
VITE_BACKEND_URL=https://YOUR-URL.railway.app
```

`.env.production`의 URL을 Railway에서 발급된 실제 URL로 교체 후 APK 빌드.

## 3. Android APK 빌드

### 전제 조건
- JDK 17 이상 설치 (현재 `C:\Program Files\Microsoft\jdk-17.0.18.8-hotspot` 사용 중)
- Android SDK (환경변수 `ANDROID_HOME` 또는 `local.properties`에 경로 설정)

### 3-1. Quasar 웹 빌드 + Capacitor sync

```bash
cd C:/work/myeon/workspace/hye_yoon1110/frontend
npx quasar build -m capacitor -T android
```

이 명령은:
- Vite로 프론트엔드 빌드
- `capacitor sync android`로 웹 에셋을 Android 프로젝트에 복사

> ESLint 오류가 있으면 빌드 중단됨. 오류 수정 후 재실행.

### 3-2. Gradle APK 빌드

```bash
cd C:/work/myeon/workspace/hye_yoon1110/frontend/src-capacitor/android
bash gradlew assembleRelease
```

빌드 성공 시:
```
BUILD SUCCESSFUL in X:XX
```

APK 생성 위치:
```
app/build/outputs/apk/release/app-release-unsigned.apk
```

> 빌드에 5~10분 소요됨.

### 3-3. APK 서명 (기기 설치용)

서명 없는 APK는 일부 기기에서 설치 불가. 서명 방법:

**방법 A: keytool + apksigner (CLI)**

```bash
# 키스토어 생성 (최초 1회)
keytool -genkey -v -keystore my-release-key.jks -keyalg RSA -keysize 2048 -validity 10000 -alias my-key-alias

# APK 서명
apksigner sign --ks my-release-key.jks --ks-key-alias my-key-alias \
  app/build/outputs/apk/release/app-release-unsigned.apk
```

**방법 B: Android Studio**

```bash
npx cap open android
```
→ `Build > Generate Signed Bundle / APK` → APK 선택 → 키스토어 지정 → 빌드

### 3-4. APK 기기 설치

```bash
# USB 연결 후 adb 설치
adb install app/build/outputs/apk/release/app-release-unsigned.apk

# 또는 파일 공유 앱으로 기기에 전송 후 직접 설치
```

## 5. 문제 해결

### Railway 배포 실패
- yt-dlp 설치 안 됨: `backend/nixpacks.toml` 확인
- 포트 오류: `server.js`에서 `process.env.PORT` 사용 확인

### Gradle 빌드 실패
- JDK 버전 확인: `java -version` → 17 이상이어야 함
- `local.properties`에 `sdk.dir` 경로가 올바른지 확인
- `gradlew clean` 후 재시도

### ESLint 빌드 오류
- `quasar build` 중단 시 오류 메시지의 파일과 줄 번호 확인 후 수정

### APK 설치 후 갤러리 스캔이 빈 화면
- 기기 설정 → 앱 → 미디어 매니저 → 권한 → 사진 및 동영상 권한 허용

### 다운로드 실패
- `.env.production`의 `VITE_BACKEND_URL` 확인
- Railway 대시보드에서 서버 로그 확인
- Instagram 이미지: 설정에서 Instagram 로그인 후 재시도

### Instagram 이미지 못 가져오는 경우
- Railway 로그에서 `[instagram-embed]`, `[instagram-api]` 로그 확인
- 로그인된 상태에서 시도 (Private API 1순위)
- 비공개 계정은 로그인 필수
